# 글로리매직 홈페이지 재구현

REA로 `http://magicglory.com/`의 공개 화면을 수집한 프론트엔드와 새로 구현한 Node.js/SQLite 백엔드입니다. 원본의 PHP 소스·회원 DB·비공개 데이터 복제본은 아닙니다.

## 실행

Node.js 24.22.1 이상을 설치한 Windows에서 이 폴더를 연 뒤 실행합니다. 외부 npm 의존성을 설치할 필요가 없습니다.

```powershell
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 서버는 로컬 주소에만 바인딩합니다. 에이전트가 CYS 환경에서 서버를 시작할 때에는 프로젝트 운영 규약대로 `cys run --scoped -- npm start`를 사용합니다.

현재 작업 컴퓨터에는 요청한 `admin1004` 관리자 계정을 설정했습니다. 비밀번호는 데이터베이스에 PBKDF2 해시로 저장하며 소스·압축파일에 인증 데이터를 넣지 않습니다. 이후 가입자는 일반 회원입니다. 원본 사이트의 기존 아이디·비밀번호는 이 복제본에서 사용할 수 없습니다. 관리자 로그인은 `/admin/login`, 전체 게시판 글 관리는 `/admin/boards`, 문의·회원 관리는 `/admin`입니다.

새 컴퓨터에 소스를 설치한 경우 `npm run admin:configure`로 관리자 계정을 설정하세요. 실행 중인 서버가 있다면 변경된 코드를 읽도록 종료 후 `npm start`로 다시 실행해야 합니다.

새 회원·게시물·댓글·문의·로그인 세션은 `runtime/glorymagic.sqlite`에 저장됩니다. 이 파일과 WAL/SHM 보조 파일은 실행 데이터이므로 소스 배포에 포함하지 않습니다. 데이터 백업은 서버를 종료한 뒤 SQLite 파일을 복사하거나 SQLite의 백업 기능으로 진행합니다.

## 확보한 공개 화면

- HTML 화면 415개: 홈·소개·강좌·공연·게시판 목록·페이지 번호·게시물 상세·약관 등
- 공개 게시물 상세 화면 364개. 공개 화면에서 확인된 내용과 경로를 보관합니다.
- 이미지·테마·글꼴 등 실제 확보 파일의 수와 용량은 `docs/provenance.json`에 기록되어 있습니다.
- 기존 메뉴, 드롭다운, 메인 슬라이드, 모바일 메뉴, 검색, 게시물 이동을 연결했습니다.
- 로고·배너·소개·갤러리 이미지의 원본 바이트는 `public/`에 보관합니다.

## 새 백엔드 기능

- 로컬 회원가입·로그인·로그아웃, PBKDF2 비밀번호 해시, HttpOnly 세션
- 회원 게시물 작성·수정·삭제와 작성자/관리자 권한 구분
- 공지사항 등 관리 게시판은 관리자만 작성 가능
- 댓글 저장, 게시판·제목·본문 검색, 페이지 나누기
- 회원별 비공개 1:1 문의와 관리자 답변
- 관리자 문의·회원 조회, SQLite 영속 저장
- 동일 출처 검사, 매개변수 바인딩, 요청 크기 제한과 로그인 시도 제한

관리자는 각 게시판의 ‘글쓰기·글 관리’에서 새 글을 작성·삭제할 수 있습니다. 가져온 기존 게시물도 관리자만 삭제할 수 있으며, 삭제 상태를 데이터베이스에 보관하여 목록·검색·직접 주소에서 제외합니다. 소개처럼 단일 내용으로 구성된 게시판도 기존 게시글 삭제와 새 글 작성을 지원합니다. 새 글은 별도 상세 페이지에서 수정·삭제할 수 있습니다. 원본 화면의 과거 접속자·회원 통계는 캡처 당시 표시값이며 새 서버의 실시간 집계가 아닙니다.

## 검증

```powershell
npm test
npm run build
npm run validate
```

자동 검증에는 회원·게시물 권한, 비공개 문의 분리, 관리자 답변, 다른 출처의 쓰기 차단, 로그인 실패·로그아웃, 재시작 후 저장 데이터 보존, 보관 경로의 렌더링이 포함됩니다.

`docs/desktop.png`, `docs/mobile.png`는 각각 1440×1000, 390×844의 홈 화면 확인 이미지입니다. 외부 동영상 요청을 제외한 자체 포함 HTML을 실제 Chromium으로 렌더링했습니다. 실행 중인 HTTP 사이트에 대한 전체 브라우저 검증을 뜻하지 않습니다.

## 비공개 배포 상태와 차이

비공개 사이트 프로젝트 `appgprj_6af0406df9b08191a250b178df246063`를 생성하고 `.openai/hosting.json`에 저장했습니다. 소스 업로드가 실행 환경의 네트워크 오류(`getaddrinfo() thread failed to start`)로 실패했으므로 실제 게시 URL은 아직 없습니다.

`dist/server/index.js`는 Cloudflare Workers용 ESM입니다. 비공개 사이트의 바깥 접근 제어는 ChatGPT 플랫폼 인증을 유지하고, 사이트 안에서는 요청한 별도 관리자 아이디·비밀번호 로그인을 지원합니다. 배포 설정에 D1 `DB`와 `drizzle/` 마이그레이션을 선언했습니다. 관리자 `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH`, `ADMIN_PASSWORD_SALT`는 사이트의 비밀 환경변수로 설정했습니다. 아직 소스 업로드가 네트워크 오류로 막혀 실제 배포·운영 데이터베이스 검증은 완료하지 못했습니다. R2는 아직 연결되어 있지 않습니다.

호스팅 번들은 크기를 제한하기 위해 일부 이미지를 WebP로 최적화하고 큰 파일을 원본 공개 서버에서 읽도록 구성했습니다. 완전히 독립적인 호스팅은 `public/` 파일을 R2 `BUCKET` 등에 이전하여 연결해야 합니다. 로컬 실행은 확보된 원본 이미지 파일을 그대로 제공합니다.

확보하지 못한 원본 파일, 회원 정보, 비공개 게시물, 원래 PHP/DB 내부 구조, 관리자 전체 기능, 파일 첨부/다운로드의 접근 권한과 기존 이메일 발송은 동일함을 보증할 수 없습니다. 비밀번호 재설정 이메일은 연결된 메일 서비스가 없어 성공으로 표시하지 않습니다. 외부 YouTube 영상은 원본처럼 외부 서비스에 의존합니다.

## 파일 구조

| 경로 | 역할 |
|---|---|
| `server.mjs` | 로컬 HTTP 서버와 SQLite 어댑터 |
| `worker/app.js` | API·권한·게시판·문의 라우팅 |
| `public/replica.js` | 복구한 프론트엔드 상호작용 |
| `public/replica.css` | 반응형 보완과 새 양식 스타일 |
| `data/pages.json` | 공개 페이지별 원본 화면 보관 |
| `data/imported-posts.json` | 확인된 공개 게시물 인덱스 |
| `data/catalog.json` | 원본 경로·양식·링크와 REA 근거 ID |
| `migrations/0001_core.sql` | 새 백엔드 데이터 구조 |
| `docs/provenance.json` | 확보 범위와 확인하지 못한 범위 |
| `tests/backend.test.mjs` | 백엔드 및 보관 경로 검증 |

원본 수집 자료와 실행 데이터, 관리자 비밀번호·비밀 키를 Git 원격 저장소에 임의로 추가하지 마세요. 이 소스에는 실제 관리자 비밀번호나 원본 회원 DB가 포함되어 있지 않습니다.
