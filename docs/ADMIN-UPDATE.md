# 관리자 기능 업데이트

현재 작업 컴퓨터의 관리자 아이디는 `admin1004`이며 요청한 비밀번호로 설정했습니다. 실제 브라우저에서 로그인하여 관리자 권한을 확인했습니다. 비밀번호 원문이나 운영 데이터베이스는 이 업데이트 파일에 포함하지 않습니다.

현재 실행 중인 서버는 이전 코드를 읽고 있으므로 서버를 실행한 터미널에서 `Ctrl+C`로 종료한 뒤 해당 프로젝트 폴더에서 `npm start`로 다시 실행해야 합니다.

## 사용 방법

1. `/admin/login`에서 관리자 계정으로 로그인합니다.
2. 각 게시판 상단의 **글쓰기**로 게시물을 등록합니다.
3. **글 관리**로 이동하면 선택한 게시판의 기존 글과 새 글을 삭제할 수 있습니다.
4. 전체 게시판 관리 화면은 `/admin/boards`입니다.
5. 소개 등 단일 내용 게시판에서는 **기존 게시글 삭제**로 기존 내용을 제거할 수 있습니다.

가져온 기존 게시물의 삭제 상태는 별도 데이터베이스 테이블에 저장합니다. 관리자 이외의 회원은 기존 게시물을 삭제할 수 없으며, 삭제한 글은 목록·검색·상세 주소에서 제외됩니다. 이미지 원본 파일이나 최초 수집 자료 자체를 지우지는 않습니다.

## 업데이트 파일 적용

`glorymagic-admin-update.zip`은 변경된 소스만 담은 파일입니다. 앞서 받은 전체 소스의 `package.json`이 있는 폴더에 덮어쓴 뒤 서버를 재시작하세요. 기존 `runtime/` 데이터는 덮어쓰지 않습니다. 새 PC라면 `npm run admin:configure`로 관리자 계정을 먼저 설정하세요.

## 검증과 배포 상태

- 요청한 관리자 계정의 실제 브라우저 로그인 및 관리자 역할 확인
- 각 게시판에서 관리자 글 작성·삭제, 일반 회원의 삭제 제한 확인
- 가져온 게시물·단일 내용 게시판의 삭제 및 상세 주소 제외 확인
- 총 9개 자동 검증 묶음 통과
- D1 `DB` 바인딩, Drizzle 마이그레이션, 관리자 인증용 비밀 환경변수 준비

배포할 기존 비공개 사이트는 `appgprj_6af0406df9b08191a250b178df246063`입니다. 소스 업로드에서 `getaddrinfo() thread failed to start` 오류가 발생하여 실제 게시까지 완료하지 못했습니다. 네트워크가 허용되는 실행 환경에서 기존 사이트 ID를 유지한 채 소스를 업로드하고 배포해야 합니다. 아직 작동하는 원격 게시 URL은 없습니다.
